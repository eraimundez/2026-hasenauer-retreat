A Typical PK Dataset
Clinical trial data is sparse by design — 2–5 blood draws per patient, not a dense time series. The population model pools across hundreds of patients to estimate PK parameters.

Figure: Single IV dose PK profile from a Ph1 trial

A Typical PopPK Model
Level 1 — Structural (2-cmt, IV bolus)
dAc/dt = −(CL/V1) · Ac − (Q/V1) · Ac + (Q/V2) · Ap
dAp/dt =  (Q/V1) · Ac − (Q/V2) · Ap
C = Ac / V1
Ac(0) = Dose,  Ap(0) = 0
Central ⇄ peripheral; elimination only from central.

Level 2 — Between-subject variability (BSV)
pi = ppop · exp(ηi),  ηi ~ 𝒩(0, ωp²)
For each PK parameter (CL, V1, Q, …) — if supported by data

Level 3 — Residual unexplained variability (RUV)
Yij = f(θi, tij) · (1 + εij),  εij ~ 𝒩(0, σ²)
